# An Applied Econometric Analysis of Foreign Exchange Spillovers during the 2007–2008 Financial Crisis
## Executive Summary
This repository contains an applied econometric framework designed to quantify foreign exchange rate spillovers and monetary transmission volatility during the 2007–2008 Global Financial Crisis. Using time-series analysis, stationarity testing (ADF), and Ordinary Least Squares (OLS) regression models, the project evaluates the impact of systemic liquidity contraction on currency valuation dynamics.

## Key Research Questions
1. How did liquidity stress in major money markets transmit to foreign exchange volatility between 2007 and 2008?
2. What was the statistical significance of central bank interest rate interventions on currency stabilization?

## Methodology
- **Time-Series Econometrics**: Stationarity verification using Augmented Dickey-Fuller (ADF) tests.
- **Regression Modeling**: OLS estimation assessing exchange rate spillovers across key currency pairs.
- **Data Visualizations**: Structural break analysis and impulse response simulations located in `/figures`.
